# Header

## Purpose

Представляет шапку сайта.

Отвечает за общий HTML-каркас `<header>` и расположение дочерних узлов внутри него.

Не содержит реализацию компонентов.

---

## Responsibilities

* вывод HTML-контейнера шапки;
* определение структуры и расположения дочерних узлов;
* предоставление точек вставки (`slots`) для генератора артефактов.

---

## Does not implement

* вывод названия сайта;
* вывод логотипа;
* вывод навигации;
* вывод поиска;
* любую другую функциональность дочерних компонентов.

Каждый дочерний узел отвечает за собственное представление посредством своего ресурса.

---

## Slot composition

Типичный состав:

```text
Header
├── Site Title
└── Navigation
```

Порядок и набор дочерних узлов определяются соответствующей `Composition`.

---

## Architectures

Для каждой поддерживаемой архитектуры предоставляется собственный ресурс.

```text
resources/
└── template-part/
    └── header/
        ├── classic/
        │   └── header.php
        └── block/
            └── header.html
```
