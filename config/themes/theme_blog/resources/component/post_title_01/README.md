# post_title_01

## Purpose

Post Title — отображает заголовок текущей записи.

## Responsibilities

- вывод заголовка записи;
- использование на страницах одиночного просмотра (`is_singular()`).

## Strategy

Использует стратегию `cached`.

Предназначен для повторного использования без изменения результата в рамках одного запроса.

## Styling

Узел не содержит собственных CSS.

Использует стандартные HTML-элементы и классы WordPress.

## Consumers

Используется шаблонами `single.php` и другими шаблонами одиночного просмотра.
