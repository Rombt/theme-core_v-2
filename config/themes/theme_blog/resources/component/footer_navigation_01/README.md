# footer_navigation_01

## Purpose

Footer Navigation — отображает меню футера сайта.

## Responsibilities

- проверка существования меню;
- вывод зарегистрированного меню `footer`;
- использование стандартного WordPress API.

## Styling

Узел не содержит собственных CSS.

Использует стандартную HTML-разметку и может оформляться через `theme.json`.

## Consumers

Используется в `footer.php` и других компонентах нижней части сайта.
