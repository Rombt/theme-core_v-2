# archive_title_01

## Purpose

Archive Title — отображает заголовок и описание текущего архива.

## Responsibilities

- вывод заголовка архива;
- вывод описания архива при его наличии.

## Styling

Узел не содержит собственных CSS.

Использует стандартные HTML-элементы и классы WordPress.

## Consumers

Используется шаблонами архивов, категорий, тегов, авторов, дат, поиска и страницы блога.
