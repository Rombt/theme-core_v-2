# hero_navigation_01

## Purpose

Hero Navigation — отображает меню Hero-блока сайта.

## Responsibilities

- проверка существования меню;
- вывод зарегистрированного меню `hero`;
- использование стандартного WordPress API.

## Styling

Узел не содержит собственных CSS.

Использует стандартную HTML-разметку и может оформляться через `theme.json`.

## Consumers

Используется Hero-компонентами и шаблонами, содержащими Hero-блок.
