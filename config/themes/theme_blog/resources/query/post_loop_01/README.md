# post_loop_01

## Purpose

Post Loop — выполняет стандартный WordPress Loop и отображает список записей.

## Responsibilities

- выполнение цикла WordPress;
- передача каждой записи узлу `content_01`;
- вывод постраничной навигации;
- отображение шаблона `content-none` при отсутствии записей.

## Styling

Узел не содержит собственных CSS.

Использует стандартную HTML-разметку и классы WordPress.

## Consumers

Используется шаблонами архивов, категорий, тегов, поиска, страницы блога и другими шаблонами, отображающими список записей.
