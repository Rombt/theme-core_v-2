# query_01

## Purpose

Posts Query — выполняет стандартный WordPress Loop.

## Responsibilities

- обход результатов запроса;
- передача каждой записи узлу `content_01`;
- вывод навигации по страницам;
- отображение шаблона `content-none` при отсутствии записей.

## Styling

Узел не содержит собственных CSS.

Использует стандартную разметку и классы WordPress.

## Consumers

Используется архивными шаблонами, страницей блога, поиском и другими шаблонами, работающими со списком записей.
