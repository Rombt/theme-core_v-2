# page_title_01

## Purpose

Page Title — отображает заголовок текущей страницы.

## Responsibilities

- вывод заголовка страницы;
- использование только на страницах (`is_page()`).

## Strategy

Использует стратегию `custom`.

Компонент реализует собственную логику отображения и не использует стратегию обработки по умолчанию.

## Styling

Узел не содержит собственных CSS.

Использует стандартные HTML-элементы и классы WordPress.

## Consumers

Используется шаблоном `page.php` и другими шаблонами, отображающими отдельные страницы.
