# page_content_01

## Purpose

Page Content — отображает содержимое текущей страницы.

## Responsibilities

- вывод `the_content()`;
- поддержка Gutenberg;
- поддержка Elementor;
- вывод постраничной навигации через `wp_link_pages()`.

## Styling

Узел не содержит собственных CSS.

Для оформления используются:

- стандартные классы WordPress;
- стили, определённые в `theme.json`.

## Consumers

Используется шаблонами страниц (`page.php`) и другими шаблонами, отображающими содержимое страницы.
