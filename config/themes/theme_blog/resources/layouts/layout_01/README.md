# layout_01

## Purpose

Main Layout — базовый контейнер страницы.

Отвечает за общую структуру документа и определяет область вывода основного содержимого.

## Responsibilities

- подключение `header.php`;
- подключение `footer.php`;
- вывод области `<main>`;
- вывод содержимого записи через WordPress Loop.

## Architecture

- Classic Theme;
- Elementor-first;
- Hybrid Features.

Layout не содержит бизнес-логики и не определяет внешний вид страницы.

## Styling

Узел не содержит собственных CSS.

Для оформления используются:

- стандартные HTML-элементы;
- стандартные классы WordPress;
- глобальные стили, определённые в `theme.json`.

## Consumers

Используется PHP-шаблонами темы как базовый layout верхнего уровня.
