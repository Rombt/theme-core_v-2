# widgets_01

## Purpose

Widget Area — отображает основную область виджетов темы.

## Responsibilities

- проверка наличия активных виджетов;
- вывод зарегистрированной области `primary-sidebar`.

## Styling

Узел не содержит собственных CSS.

Использует стандартную HTML-разметку и WordPress API.

## Consumers

Используется в `sidebar.php`, а также в шаблонах, поддерживающих боковую колонку.
