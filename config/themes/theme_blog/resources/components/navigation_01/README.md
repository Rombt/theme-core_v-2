# navigation_01

## Purpose

Primary Navigation — отображает основное меню сайта.

## Responsibilities

- проверка существования меню;
- вывод зарегистрированного меню `primary`;
- использование стандартного WordPress API.

## Styling

Узел не содержит собственных CSS.

Использует стандартную HTML-разметку и может оформляться через `theme.json`.

## Consumers

Используется в `header.php` и других layout-компонентах, требующих отображения основного меню сайта.
