# site_title_01

## Purpose

Site Title — отображает название сайта.

## Responsibilities

- вывод названия сайта;
- ссылка на главную страницу;
- использование `h1` на главной странице и `p` на остальных.

## Styling

Узел не содержит собственных CSS.

Использует стандартный класс `wp-block-site-title`, оформление которого может задаваться через `theme.json`.

## Consumers

Используется в `header.php` и других компонентах, отображающих фирменную информацию сайта.
