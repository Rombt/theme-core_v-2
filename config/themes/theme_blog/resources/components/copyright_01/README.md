# copyright_01

## Purpose

Copyright — отображает информацию об авторских правах сайта.

## Responsibilities

- вывод текущего года;
- вывод названия сайта;
- отображение стандартного уведомления об авторских правах.

## Strategy

Использует стратегию `readonly`.

Компонент формирует неизменяемое представление и не требует дополнительной обработки.

## Styling

Узел не содержит собственных CSS.

Использует стандартную HTML-разметку.

## Consumers

Используется в `footer.php` и других компонентах нижней части сайта.
