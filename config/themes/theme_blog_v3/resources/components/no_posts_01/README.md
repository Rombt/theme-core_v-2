# no_posts_01

## Purpose

Displays a message when no posts are available.

## Supported Architectures

- Classic Theme (`component.classic.php`)
- Block Theme (`component.block.html`)

## Responsibilities

- display a message when the post loop contains no posts.

## Styling

The component contains no dedicated CSS.

It relies on standard HTML and global theme styles.

## Consumers

Used by `post_loop_01` as the content of its empty-state slot.
