# copyright_01

## Purpose

Displays the site's copyright information.

## Supported Architectures

- Classic Theme (`component.classic.php`)
- Block Theme (`component.block.html`)

## Responsibilities

- display the current year;
- display the site title;
- display the copyright notice.

## Strategy

Uses the `readonly` strategy.

The component produces a static representation and requires no additional processing.

## Styling

The component contains no dedicated CSS.

It relies on standard HTML and WordPress block markup.

## Consumers

Typically used by the site footer and other footer-related compositions.
