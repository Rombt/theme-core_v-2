# query_01

## Purpose

Posts Query — выполняет стандартный WordPress Loop.

## Responsibilities

- выполнение WordPress Loop;
- предоставление текущей записи дочерним компонентам;
- вывод списка записей;
- вывод навигации по страницам;
- отображение содержимого при отсутствии записей.

## Resource Files

- `query.classic.php` — реализация для Classic Theme.
- `query.block.html` — реализация для Block Theme.

## Architecture

Поддерживаемые архитектуры:

- Classic Theme;
- Block Theme.

Ресурс отвечает за выполнение цикла WordPress и определяет место вывода дочерних компонентов.

## Slots

| Slot | Purpose |
|------|---------|
| slot_1 | Представление одной записи. |
| slot_2 | Представление состояния отсутствия записей. |

## Styling

Ресурс не содержит собственных CSS.

Для оформления используются стандартные классы WordPress и глобальные стили темы.
