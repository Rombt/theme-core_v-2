# widgets_01

## Purpose

Displays the primary widget area.

## Supported Architectures

- Classic Theme (`component.classic.php`)
- Block Theme (`component.block.html`)

## Responsibilities

- display the primary widget area;
- provide a location for sidebar content in the target architecture.

## Styling

The component contains no dedicated CSS.

It relies on standard HTML and WordPress block markup.

## Consumers

Used by sidebar compositions and templates that include a sidebar.
