# site_title_01

## Purpose

Displays the site title.

## Supported Architectures

- Classic Theme (`component.classic.php`)
- Block Theme (`component.block.html`)

## Responsibilities

- display the site title;
- provide a link to the home page;
- use the native implementation of the target architecture.

## Styling

The component contains no dedicated CSS.

It relies on the standard `wp-block-site-title` class and may be styled via `theme.json`.

## Consumers

Typically used by the site header and other compositions displaying site branding.
