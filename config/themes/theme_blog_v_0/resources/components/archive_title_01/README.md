# archive_title_01

## Purpose

Displays the title and description of the current archive.

## Supported Architectures

- Classic Theme (`component.classic.php`)
- Block Theme (`component.block.html`)

## Responsibilities

- display the archive title;
- display the archive description when available.

## Styling

The component contains no dedicated CSS.

It relies on standard WordPress block markup and default theme styling.

## Consumers

Used by archive-related templates, including:

- archive;
- category;
- tag;
- author;
- date;
- search;
- blog index.
