Architecture of Theme Description / Theme Specification
       «Мы построили механизм обработки конфигурации тем.
              Теперь нужно спроектировать саму модель данных (DSL/Specification),
              которая сможет выразить любую WordPress-тему и
              стать источником данных для ThemeDefinition.»

       Architecture of Theme Description
              То есть ответить на вопросы:
                     Что вообще может существовать в теме?
                     Какие концепции являются первичными?
                     Как выразить любую тему через эти концепции?
                     Что должно стать содержимым ConfigurationDomain?
