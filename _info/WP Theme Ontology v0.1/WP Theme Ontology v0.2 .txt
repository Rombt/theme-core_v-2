WP THEME ONTOLOGY v0.2
Исследование предметной области WordPress Theme
Этап №1 — Анализ множества существующих тем

Статус:
    Draft / Research

Цель:
    Выявить минимальный набор фундаментальных концепций, достаточных для описания
    подавляющего большинства WordPress тем и последующего проектирования
    Theme Description Architecture.

Исследование считается завершённым, если:
    Любая исследованная тема полностью описывается моделью.
    Из модели детерминированно строится ThemeDefinition.
    Из ThemeDefinition детерминированно генерируются артефакты.
    Новые типы тем не требуют изменения метамодели.
    Каждая концепция имеет единственное место в модели.
    Theme Description становится единственным входом theme-core v-2.


================================================================================
1. ИСХОДНАЯ ГИПОТЕЗА
================================================================================

    Первоначально была предложена следующая метамодель:

    Theme
    ├── Design System
    ├── Structure
    ├── Behavior
    ├── Distribution
    └── Demo

    Однако анализ показал, что понятия Structure и Behavior являются слишком
    широкими и фактически скрывают внутри себя несколько различных концепций.

    Поэтому первоначальная гипотеза была пересмотрена.

================================================================================
2. МЕТОД ИССЛЕДОВАНИЯ
================================================================================

    Было проанализировано 30 популярных коммерческих
        WordPress тем различных категорий:

        - News
        - Blog
        - Magazine
        - Corporate
        - Landing
        - Portfolio
        - Ecommerce
        - LMS
        - Directory
        - Real Estate
        - Travel
        - SaaS

    Для каждой темы были собраны ответы на вопросы:

        1. Что умеет тема?
        2. Что содержит тема?
        3. Что можно изменять?
        4. Что является обязательным?
        5. Что является вариацией?

    После этого был произведён поиск повторяющихся концепций и инвариантов.

================================================================================
3. ГЛАВНОЕ НАБЛЮДЕНИЕ
================================================================================

    Практически всё, что встречается в темах, можно разделить на три класса:

        1. Что отображается.
        2. Как это отображается.
        3. Что система умеет делать.

    Примеры:

        Product -> что отображается.

        Product Card -> как отображается.

        Wishlist -> что система умеет делать.

    Данное наблюдение стало основой для построения новой метамодели.

================================================================================
4. ВЫЯВЛЕННЫЕ ИНВАРИАНТЫ
================================================================================

    4.1 Content
    -------------------------------------------------------------------------------

        Описывает предметные сущности, существующие внутри темы.
            Примеры:
                Post
                Article
                Product
                Course
                Lesson
                Property
                Listing
                Portfolio
                Project
                Service
                Team
                Author
                Publisher
                Event
                Hotel
                Tour
                Rental

        Наблюдение:
            Несмотря на различия предметных областей,
                все они являются разновидностями контента.

    4.2 Presentation
    -------------------------------------------------------------------------------

        Описывает способы отображения контента.
            Примеры:
                Template
                Layout
                Section
                Card
                Grid
                Masonry
                Gallery
                Carousel
                Hero
                Table
                Search Form
                Sidebar
                Navigation

        Наблюдение:
            Практически все вариации тем относятся именно к Presentation.

        Примеры:
            Product Card
            Category Layout
            Home Layout
            Hero Style
            Grid
            Masonry
            Gallery

    4.3 Capabilities
    -------------------------------------------------------------------------------

        Описывает возможности системы.
            Примеры:
                Search
                Booking
                Reviews
                Wishlist
                Compare
                Filters
                Maps
                Certificates
                Zoom
                Assignments
                AMP
                RTL
                Dark Mode
                Mega Menu

        Наблюдение:
            Capabilities практически никогда не являются контентом и практически никогда
                не являются способом отображения.

        Это отдельная фундаментальная категория.

    4.4 Design System
    -------------------------------------------------------------------------------

        Описывает визуальный язык темы.
            Примеры:
                Colors
                Typography
                Spacing
                Shadows
                Effects
                Animations
                Tokens
                Style Variations

        Наблюдение:
            Design System пронизывает все остальные категории,
                но сам является отдельной концепцией.

    4.5 Distribution
    -------------------------------------------------------------------------------

        Описывает поставку и сборку темы.
            Примеры:
                Assets
                Translations
                Readme
                Licenses
                Dependencies
                Packages
                Screenshots
                Build Options

    4.6 Demo
    -------------------------------------------------------------------------------

        Описывает демонстрационные данные.
            Примеры:
                Pages
                Posts
                Menus
                Media
                Widgets
                Starter Content
                Theme Options

7. ПЕРВЫЕ ВЫВОДЫ
================================================================================

    1. Structure распадается на:
        - Content
        - Presentation
    2. Behavior распадается на:
        - Capabilities
    3. Вариативность тем почти всегда находится внутри Presentation.
    4. Специализация тем почти всегда находится внутри Content и Capabilities.
    5. Design System является ортогональным измерением и влияет на все остальные категории.

9. ОТКРЫТЫЕ ВОПРОСЫ ДЛЯ ЭТАПА №2
================================================================================

    1. Является ли Composition отдельной фундаментальной концепцией
        или частью Presentation?

    2. Являются ли Templates разновидностью Presentation
        или отдельным измерением?

    3. Следует ли выделить Navigation в отдельную концепцию?

    4. Следует ли выделить Integrations в отдельную концепцию?

    5. Можно ли выразить абсолютно любую коммерческую тему через данную модель?

    6. Достаточно ли данной модели для построения Theme Description Language?
