THEME-CORE V-2
ФИНАЛЬНОЕ ИССЛЕДОВАНИЕ THEME SPECIFICATION
КОНЦЕПЦИЯ №3 — TEMPLATE
ИТОГОВОЕ САММАРИ
(v1.0.0)


1. ВЫВОД
================================================================================

    Концепция Template не подтверждается как самостоятельная фундаментальная
    концепция Theme Specification.

    Она является производной от Composition.


2. ОБОСНОВАНИЕ
================================================================================

    Исследование показало, что вся информация, необходимая для построения
    WordPress Template, уже содержится в Composition.

    Composition определяет:

        • идентификатор шаблона;

        • тип template;

        • структуру шаблона;

        • состав и иерархию элементов.

    Дополнительной декларативной информации Template не содержит.


3. RESOLUTION
================================================================================

    Resolution не требуется строить отдельный Template IR.

    Достаточно построения Composition IR, содержащего композиции типа
    "template".


4. ARTIFACT GENERATION
================================================================================

    Генерация шаблонов является обязанностью CompositionArtifactGenerator.

    Генератор работает исключительно с Composition IR.

    Отдельный Template Generator не требуется.


5. TEMPLATES.PHP
================================================================================

    Существующий канал templates.php содержит сведения о расположении файлов,
    а не описание темы.

    Данная информация относится к реализации и не является фундаментальной
    частью Theme Specification.

    Канал требует дополнительной проверки на последующих этапах исследования.
    Если не будет найдено концепций, использующих его как единственный источник
    информации, он может быть исключён из окончательной версии Theme
    Specification.


6. ИТОГОВЫЙ ВЕРДИКТ
================================================================================

    • Template не является самостоятельной фундаментальной концепцией.

    • Отдельный Template IR не требуется.

    • Архитектура Theme Specification упрощается.

    • Предварительный статус концепции:

        REJECTED (DERIVED)
