ИССЛЕДОВАНИЕ ПРОМЕЖУТОЧНОГО ПРЕДСТАВЛЕНИЯ (IR)
ЭТАП 2. ПРОВЕРКА IR-УЗЛА ENTITY
ПРОМЕЖУТОЧНЫЕ РЕЗУЛЬТАТЫ
(v0.1.0)


1. ОБЪЕКТ ИССЛЕДОВАНИЯ
================================================================================

    Проверяется гипотеза о фундаментальности IR-узла:
        Entity

    Минимальное описание узла:
        return [

            'post' => [
                'fields' => [
                    'title',
                    'content',
                    'excerpt',
                    'date',
                ],
            ],

            'category' => [
                'fields' => [
                    'name',
                    'description',
                    'slug',
                ],
            ],

    ];


2. ЦЕЛЬ ПРОВЕРКИ
================================================================================

    Установить, обладает ли Entity собственной семантикой генерации
    артефактов либо используется исключительно как источник информации
    для других частей компилятора.


3. ПОИСК СОБСТВЕННОГО ГЕНЕРАТОРА
================================================================================

    Была предпринята попытка найти генератор, который естественным образом
    работает непосредственно с Entity.

    Рассматривались различные варианты:

        • PHP Entity Class
        • Repository
        • REST Schema
        • GraphQL Schema
        • Validation
        • SQL Schema
        • Metadata
        • Runtime Models

    Во всех случаях оказалось, что генерация требует дополнительных
    платформенных знаний либо относится к другой подсистеме.


4. ПОИСК СОБСТВЕННЫХ АРТЕФАКТОВ
================================================================================

    Была предпринята попытка определить артефакты, возникающие исключительно
    из Entity.

    Самостоятельных артефактов обнаружить не удалось.

    На данный момент цепочка

        Entity
            ↓
        Generator
            ↓
        Artifact
            ↓
        Published Output

    не подтверждается.


5. ОБНАРУЖЕННОЕ ПОВЕДЕНИЕ ENTITY
================================================================================

    Вместо самостоятельной генерации наблюдается другое поведение.

    Entity используется как источник информации
    для других генераторов.

    Например:

        Query
            ↓
        использует Entity

        Composition
            ↓
        использует Entity

        Workflow
            ↓
        использует Entity

    Таким образом Entity проявляет себя не как источник артефактов,
    а как источник данных.


6. ВЫЯВЛЕННОЕ ПРОТИВОРЕЧИЕ
================================================================================

    Во втором этапе исследования была использована гипотеза:

        Каждый фундаментальный IR-узел
        обязан иметь собственного генератора
        и собственные артефакты.

    Исследование Entity не подтвердило данную гипотезу.

    Возникло два возможных объяснения.

        Вариант 1.

            Entity не является фундаментальным IR-узлом.

        Вариант 2.

            Критерий фундаментальности сформулирован слишком жёстко.


7. НОВАЯ ГИПОТЕЗА
================================================================================

    В процессе исследования появилась альтернативная модель.

    Фундаментальный IR-узел может выполнять одну из трёх ролей.

        1. Генерировать собственные артефакты.

        2. Предоставлять информацию другим генераторам.

        3. Выполнять обе функции одновременно.

    При такой модели Entity остаётся фундаментальным узлом,
    несмотря на отсутствие собственного генератора артефактов.


8. ПРОМЕЖУТОЧНЫЙ ВЫВОД
================================================================================

    На текущем этапе исследования не найдено ни одного убедительного
    доказательства того, что Entity самостоятельно порождает артефакты.

    При этом имеются признаки того, что Entity представляет собой
    самостоятельный информационный слой, используемый несколькими
    независимыми генераторами.

    Окончательный статус Entity пока не определён.

    Для продолжения исследования требуется пересмотреть критерий
    фундаментальности IR-узла либо подтвердить существование
    самостоятельного генератора для Entity.
