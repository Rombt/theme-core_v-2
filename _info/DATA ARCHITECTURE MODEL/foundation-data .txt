==================================================
FOUNDATION DATA
==================================================

Foundation Data — это самый нижний и самый базовый слой всей архитектуры theme-core v-2.

Проще говоря:

Foundation Data — это набор фундаментальных правил, на основе которых вообще может существовать сайт.

Если представить архитектуру theme-core v-2 как строительство дома,
то Foundation — это не сам дом, не мебель, не комнаты и даже не планировка.

Foundation — это:
    стандарты строительства,
    размеры блоков,
    допустимые материалы,
    правила сетки,
    типы соединений,
    система координат
    и набор доступных строительных элементов.

--------------------------------------------------
ГЛАВНАЯ ИДЕЯ FOUNDATION
--------------------------------------------------

    Foundation отвечает не на вопрос:
        "Как выглядит конкретный сайт?"

    а на вопрос:
        "Какие возможности вообще существуют внутри системы?"


Foundation не описывает: конкретную страницу, конкретную секцию или конкретный контент.

Foundation описывает:
    правила и примитивы, из которых всё это потом может быть построено.

--------------------------------------------------
ПРОСТОЙ ПРИМЕР
--------------------------------------------------

Допустим, в системе существует Hero Section.

Foundation НЕ говорит: "На главной странице будет Hero"
Foundation НЕ говорит: "Hero будет синим"
Foundation НЕ говорит: "Hero будет содержать текст Modern Business Platform"

Foundation говорит только:
    "В системе существует тип секции Hero"
    "Hero умеет:
        отображать заголовок,
        отображать подзаголовок,
        отображать изображение,
        отображать кнопки"
    "Hero поддерживает:
        светлую тему,
        тёмную тему,
        выравнивание,
        spacing"

То есть Foundation описывает: что вообще умеет Hero, а не то, как именно он используется на конкретном сайте.

--------------------------------------------------
ПОЧЕМУ FOUNDATION ТАК ВАЖЕН
--------------------------------------------------

Без Foundation архитектура быстро превращается в хаос.

Например:

    если каждая секция:
        использует свои размеры,
        свои цвета,
        свои правила spacing,
        свои breakpoints,
        свои схемы данных,

    то система становится:
        непредсказуемой,
        плохо расширяемой,
        плохо поддерживаемой.

Foundation нужен для того, чтобы вся система говорила на одном архитектурном языке.

--------------------------------------------------
ЧТО ИМЕННО ВХОДИТ В FOUNDATION DATA
--------------------------------------------------

    Foundation включает в себя всё, что определяет базовые правила системы.

    --------------------------------------------------
    1. DESIGN TOKENS
    --------------------------------------------------

        Это глобальные значения дизайна.

        Например:
            colors.primary
            colors.secondary
            spacing.md
            radius.lg
            shadow.soft

        То есть:
            не конкретные CSS стили,
            а система дизайн-примитивов.

    --------------------------------------------------
    2. TYPOGRAPHY SYSTEM
    --------------------------------------------------

        Это правила типографики.

        Например:
            heading-xl
            heading-lg
            body-md
            caption-sm

        Foundation определяет:
            какие размеры текста существуют,
            какие line-height используются,
            какие typographic scales допустимы.

    --------------------------------------------------
    3. SPACING SYSTEM
    --------------------------------------------------

        Это единая система отступов.

        Например:
            xs = 4px
            sm = 8px
            md = 16px
            lg = 32px

        Все секции системы используют одни и те же spacing primitives.

    --------------------------------------------------
    4. RESPONSIVE RULES
    --------------------------------------------------

        Foundation определяет:
            как система реагирует на разные устройства.

        Например:
            mobile
            tablet
            desktop
            wide

        Или:
            mobile = 768px
            tablet = 1024px

    --------------------------------------------------
    5. LAYOUT PRIMITIVES
    --------------------------------------------------

        Это базовые layout-конструкции.

            Например:
                container
                grid
                columns
                stack
                inline-layout

        Foundation определяет:
            какие layout primitives доступны системе.

    --------------------------------------------------
    6. SECTION SCHEMAS
    --------------------------------------------------

        Это очень важная часть.

        Schema — это описание того, какие данные принимает компонент.

        Например:
            HeroSection:
                title
                subtitle
                image
                buttons

        Foundation определяет:
            какие поля допустимы,
            какие обязательны,
            какие типы данных используются.

    --------------------------------------------------
    7. SLOT DEFINITIONS
    --------------------------------------------------

        Slots — это области, в которые что-то можно помещать.

        Например:
            Header:
                logo-slot
                navigation-slot
                actions-slot

        Foundation определяет:
            какие structural regions существуют.

    --------------------------------------------------
    8. DESIGN RULES
    --------------------------------------------------

        Это глобальные правила визуальной архитектуры.

        Например:
            все контейнеры имеют max-width
            все секции используют spacing scale
            все карточки используют одинаковую radius system

--------------------------------------------------
ЧТО FOUNDATION НЕ СОДЕРЖИТ
--------------------------------------------------

    Foundation — это не контент.

    Foundation НЕ содержит:
        тексты
        изображения
        продукты
        статьи
        страницы

    Foundation — это не composition.

    Foundation НЕ содержит:
        порядок секций
        дерево страниц
        структуру сайта

    Foundation — это не configuration.
        
        Foundation НЕ содержит:
            активную тему
            активный preset
            настройки конкретного сайта

    Foundation — это не runtime.

    Foundation НЕ содержит:
        текущее состояние рендеринга
        кэш
        runtime context

--------------------------------------------------
ВАЖНОЕ РАЗДЕЛЕНИЕ
--------------------------------------------------

Foundation определяет: что возможно в системе.

Другие слои определяют: что именно используется.

--------------------------------------------------
КЛЮЧЕВАЯ МЕНТАЛЬНАЯ МОДЕЛЬ
--------------------------------------------------

    Foundation — это архитектурный словарь системы.

    Именно Foundation определяет:
        на каком языке
        разговаривают все остальные слои архитектуры.

    Все остальные части системы - опираются на Foundation и используют его правила.

--------------------------------------------------
КЛЮЧЕВОЙ ВЫВОД
--------------------------------------------------

Foundation Data — это не описание сайта.

Foundation Data — это описание фундаментальных возможностей, ограничений, правил и строительных примитивов, 
    из которых потом может быть собран нужный сайт внутри theme-core v-2.
