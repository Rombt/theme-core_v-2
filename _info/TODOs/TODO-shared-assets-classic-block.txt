SHARED ASSETS FOR CLASSIC AND BLOCK ARCHITECTURES
==================================================

STATUS:
    Deferred

PRIORITY:
    Future Architecture

==================================================
PROBLEM
==================================================

    Classic и Block архитектуры используют одинаковые
    итоговые frontend CSS/JS Assets, однако текущая модель
    Asset Resource и pipeline обрабатывают Assets
    в контексте конкретной архитектуры.

    Это не позволяет декларативно описать один общий Asset,
    который используется обеими архитектурами без
    дублирования регистрации и архитектурно-зависимых файлов.

==================================================
TARGET ARCHITECTURE
==================================================

    В будущих версиях Theme Core необходимо рассмотреть
    поддержку общих Assets для Classic и Block.

    Общий Asset должен иметь единое описание и быть доступен
    обеим архитектурам, при этом архитектурные представления
    Resources (classic.php и block.html) должны оставаться
    раздельными.

    Решение должно учитывать не только frontend CSS/JS bundles,
    но и границы применимости к другим типам Assets
    (например изображениям и шрифтам).

==================================================
EXPECTED RESULT
==================================================

    - возможность объявить Asset один раз для Classic и Block;
    - отсутствие необходимости дублировать общие Asset
      registrations;
    - сохранение разделения архитектурных представлений
      Resources;
    - согласованная обработка общих Assets в build pipeline.

==================================================
DO NOT IMPLEMENT IN MVP
==================================================

    Поддержку общих Assets для Classic и Block не реализовывать
    на стадии MVP.

    Вернуться к проектированию и реализации этой возможности
    в одной из следующих версий после стабилизации текущей
    модели Assets и build pipeline.
