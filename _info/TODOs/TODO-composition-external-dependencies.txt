COMPOSITION EXTERNAL DEPENDENCIES

STATUS:
    Deferred

PRIORITY:

==================================================
PROBLEM
==================================================

    В текущей реализации некоторые application-wide объекты
    (например Logger и Diagnostics) участвуют в построении
    Composition Layer.

    При этом данные объекты принадлежат ApplicationContext
    и не должны становиться частью результирующего
    CompositionRuntime.

    В настоящее время допустимо временно дублировать такие
    объекты в Composition Definitions ради упрощения
    архитектуры и ускорения разработки.

==================================================
TARGET ARCHITECTURE
==================================================

    В будущем Composition Layer должен поддерживать
    External Dependencies.

    External Dependency представляет объект,
    находящийся вне Composition Runtime,
    но доступный для Dependency Resolution.

    Источником таких зависимостей должен выступать
    ApplicationContext.

==================================================
EXPECTED RESULT
==================================================

    Composition Runtime содержит только собственные
    composition services.

    Application-wide объекты остаются исключительно
    в ApplicationContext.

    Dependency Resolver способен разрешать зависимости
    из двух источников:

        - Composition Service Registry
        - ApplicationContext

==================================================
BENEFITS
==================================================

    - устранение дублирования сервисов;
    - более чистые архитектурные границы;
    - корректное разделение lifecycle уровней;
    - отсутствие необходимости исключать сервисы
      из CompositionRuntime после его построения;
    - упрощение сопровождения архитектуры.

==================================================
DO NOT IMPLEMENT NOW
==================================================

    Текущая версия проекта сознательно использует
    упрощённую модель.

    Реализацию External Dependencies отложить до момента,
    когда Composition Layer стабилизируется и будет
    завершена базовая Runtime архитектура.
