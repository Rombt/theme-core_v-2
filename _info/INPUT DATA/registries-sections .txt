==================================================
REGISTRIES.sections
==================================================


Назначение
--------------------------------------------------

    REGISTRIES.sections — registry semantic composition units.

    Раздел отвечает за:
        - регистрацию section types
        - описание semantic structures
        - описание allowed composition
        - описание section slots
        - предоставление section capabilities


Главная идея
--------------------------------------------------

    Section — это semantic structural block страницы.

    Section описывает:
        - semantic role
        - structural purpose
        - composition boundaries

    Section НЕ является:
        - renderer template
        - page instance
        - platform-specific markup


Типичные sections
--------------------------------------------------

    Например:
        - hero
        - features
        - faq
        - pricing
        - gallery
        - footer
        - testimonials


Architectural роль
--------------------------------------------------

    Sections формируют: semantic page structure.

    Section может определять:
        - allowed components
        - allowed layouts
        - slots
        - default composition
        - content areas

    Но НЕ определяет: platform rendering.


Главный architectural принцип
--------------------------------------------------

    section definition = описание semantic composition unit.

    section instance = конкретное использование section внутри composition tree.
