РЕАЛИЗАЦИЯ РЕЗУЛЬТАТОВ ИССЛЕДОВАНИЯ
КОНЦЕПЦИЯ №1 — METADATA
ТЕХНИЧЕСКОЕ ЗАДАНИЕ
(v1.0.0)


ЦЕЛЬ
================================================================================

    Реализовать полноценную поддержку фундаментальной концепции Metadata
    внутри ThemeCore без изменения существующей архитектуры Theme Specification.


ОБЩИЕ ПРИНЦИПЫ
================================================================================

    Реализация должна соответствовать архитектурной модели:

        Theme Specification
                ↓
            Resolution
                ↓
            Metadata IR
                ↓
        Artifact Generators

    Metadata должна рассматриваться исключительно как декларативное описание темы.

    Генерация артефактов не должна использовать Theme Specification напрямую.


ЭТАП 1. РАСШИРЕНИЕ THEME SPECIFICATION
================================================================================

    Расширить структуру package.php до полноценного описания Metadata.
    При этом сохранить существующую архитектуру каналов.
    Новый канал создавать запрещается.


ЭТАП 2. ПОСТРОЕНИЕ METADATA IR
================================================================================

    Реализовать Resolution, преобразующий package.php в Metadata IR.

    Resolution обязан:
        - выполнить валидацию;
        - выполнить нормализацию;
        - построить внутреннюю модель Metadata;
        - исключить неоднозначности.

    Resolution не должен выполнять генерацию артефактов.


ЭТАП 3. ИНТЕГРАЦИЯ С THEME IR
================================================================================

    Metadata IR должен стать частью общего Theme IR.
    Все генераторы должны получать Metadata исключительно через Theme IR.
    Прямое обращение к package.php запрещается.


ЭТАП 4. ПОДГОТОВКА ГЕНЕРАТОРОВ
================================================================================

    Подготовить инфраструктуру для будущих генераторов:
        - style.css Generator;
        - readme Generator;
        - Marketplace Generator;
        - других публикационных артефактов.

    На данном этапе допускается отсутствие самих генераторов.

    Необходимо обеспечить возможность их последующего подключения без изменения Metadata IR.


ЭТАП 5. ПРОВЕРКА
================================================================================

    Подтвердить следующие свойства реализации.

        ✓ package.php остаётся единственным источником Metadata.
        ✓ Resolution выполняет только преобразование.
        ✓ Metadata IR является единственным источником данных для Artifact Generators.
        ✓ Архитектура Theme Specification остаётся неизменной.
        ✓ Генераторы не зависят напрямую от Theme Specification.


ОЖИДАЕМЫЙ РЕЗУЛЬТАТ
================================================================================

    После завершения реализации Metadata должна пройти полный жизненный цикл.

        package.php
            ↓
        Resolution
            ↓
        Metadata IR
            ↓
        Artifact Generators
            ↓
        Published Artifacts

    Тем самым концепция Metadata станет первой полностью реализованной публикационной подсистемой ThemeCore,
        соответствующей архитектурной модели, подтверждённой исследованием.
