РЕАЛИЗАЦИЯ РЕЗУЛЬТАТОВ ИССЛЕДОВАНИЯ
КОНЦЕПЦИЯ №4 — ASSET
ТЕХНИЧЕСКОЕ ЗАДАНИЕ
(v1.0.0)


ЦЕЛЬ
================================================================================
    Реализовать полноценную поддержку фундаментальной концепции Asset
    внутри ThemeCore без изменения архитектуры Theme Specification.


ОБЩИЕ ПРИНЦИПЫ
================================================================================

    Реализация должна соответствовать архитектурной модели:

        Theme Specification
                ↓
            Resolution
                ↓
            Asset IR
                ↓
        Artifact Generators

    Asset представляет собой логический ресурс темы.
    Все генераторы должны работать исключительно с Asset IR.
    Прямой доступ к assets.php за пределами Resolution запрещается.


ЭТАП 1. РАСШИРЕНИЕ THEME SPECIFICATION
================================================================================

    Расширить структуру assets.php до полноценной декларативной модели
    ресурсов. 

    При этом:
        - сохранить существующий канал;
        - не изменять архитектуру Theme Specification;
        - отказаться от ориентации исключительно на физические файлы.


ЭТАП 2. ПОСТРОЕНИЕ ASSET IR
================================================================================

    Реализовать Resolution, преобразующий assets.php в Asset IR.

    Resolution обязан:

        - выполнять валидацию;
        - выполнять нормализацию;
        - разрешать зависимости между Asset;
        - строить внутреннюю модель ресурсов темы.

    Resolution не должен заниматься публикацией ресурсов.


ЭТАП 3. ИНТЕГРАЦИЯ С THEME IR
================================================================================

    Asset IR должен стать частью общего Theme IR.
    Все последующие генераторы получают информацию исключительно через Theme IR.
    Прямое использование Theme Specification запрещается.


ЭТАП 4. ПОДГОТОВКА ГЕНЕРАТОРОВ
================================================================================

    Подготовить инфраструктуру для генераторов, использующих Asset IR.
    Минимально предусмотреть возможность реализации:
        - Asset Publisher;
        - functions.php Generator;
        - theme.json Generator;
        - Build Manifest Generator.
    Подключение новых генераторов не должно требовать изменения Asset IR.


ЭТАП 5. ПРОВЕРКА
================================================================================

    Подтвердить следующие свойства реализации.

        ✓ assets.php является единственным источником описания ресурсов.
        ✓ Resolution выполняет исключительно преобразование.
        ✓ Asset IR является единственным источником данных для Artifact Generators.
        ✓ Генераторы не зависят напрямую от Theme Specification.
        ✓ Архитектура Theme Specification остаётся неизменной.


ОЖИДАЕМЫЙ РЕЗУЛЬТАТ
================================================================================

    После завершения реализации концепция Asset должна проходить полный жизненный цикл.

        assets.php
            ↓
        Resolution
            ↓
        Asset IR
            ↓
        Artifact Generators
            ↓
        Published Assets

    Тем самым Asset станет второй полностью реализованной фундаментальной
    подсистемой ThemeCore после Composition и обеспечит единый механизм
    описания, преобразования и публикации ресурсов темы.
