theme-core v-2
THEME IR RESEARCH
STAGE 0
DEFINITION OF THE RESEARCH GOAL
(v1.0.0)

Status: Approved

==================================================
1. PURPOSE
==================================================

   Определить направление дальнейшего исследования
   Theme IR и сформулировать стартовую гипотезу,
   не опираясь на существующую реализацию или
   внутреннее устройство Theme IR.

==================================================
2. INITIAL PROBLEM
==================================================

    На момент начала исследования отсутствовало чёткое понимание:
        - что представляет собой Theme IR;
        - зачем он существует;
        - какими свойствами должен обладать;
        - каким образом он должен участвовать в процессе сборки темы;
        - как он должен взаимодействовать с доменом Nodes.

    Было принято решение не исследовать существующую реализацию Theme IR и не
        проектировать его внутреннюю структуру.

    Вместо этого исследование было начато с определения конечного продукта платформы
        Theme Core и требований, которые этот продукт предъявляет к внутренней модели темы.

==================================================
3. MAIN RESEARCH QUESTION
==================================================

    Каков конечный продукт работы платформы
    Theme Core и какая внутренняя модель
    наиболее удобна для его автоматической сборки?

==================================================
4. CONCLUSIONS
==================================================


    4.1. Theme Core является компилятором тем
    ----------------------------------------------

        Результатом работы Theme Core является полностью готовая к использованию
            WordPress-тема.

        Под готовой темой понимается тема, которая:
            - автоматически сформирована;
            - устанавливается без дополнительной подготовки;
            - корректно активируется;
            - соответствует требованиям WordPress;
            - может использоваться как стартовая основа коммерческой разработки.


    4.2. Конечный результат не ограничивается одной архитектурой
    ----------------------------------------------

        Один и тот же конфигурационный пакет должен позволять получать реализации темы
            в различных поддерживаемых архитектурах WordPress.

        Следовательно, конфигурационная модель темы не должна зависеть
            от архитектуры конечной реализации.


    4.3. Theme Core не является генератором кода
    ----------------------------------------------

        Theme Core не генерирует PHP, HTML, CSS,
            JavaScript или любой другой программный код.

        Весь необходимый код уже существует внутри Nodes.


    4.4. Theme Core является системой сборки
    ----------------------------------------------

        Основная задача Theme Core заключается в автоматической сборке
            готовой темы из заранее существующих Nodes согласно выбранной архитектуре WordPress.


    4.5. Для сборки необходима архитектурно-независимая внутренняя модель
    ----------------------------------------------

        Поскольку конфигурационная модель не зависит от архитектуры конечной темы,
            а Nodes содержат лишь отдельные строительные блоки, между ними необходима
            единая внутренняя модель.

        Такая модель должна описывать тему независимо от конкретной архитектуры
            WordPress, быть удобной для процесса сборки и служить основой
            для последующего получения конечной реализации темы.

==================================================
5. STARTING HYPOTHESIS
==================================================

    Конечным продуктом Theme Core является готовая к использованию реализация темы
        в одной из поддерживаемых архитектур WordPress, автоматически собранная
        из единой конфигурационной модели.

    Следовательно, платформе необходима архитектурно-независимая внутренняя модель
        темы, ориентированная на её сборку и последующую генерацию в одну
        из поддерживаемых архитектур WordPress.

    Предполагается, что именно этой моделью и является Theme IR.

==================================================
6. RESULT
==================================================

    На данном этапе установлено, что наличие архитектурно-независимой внутренней модели
        темы является необходимым следствием требований, предъявляемых к платформе
        Theme Core.

    Следующий этап исследования должен определить, какими свойствами должна
        обладать эта модель и действительно ли Theme IR предназначен для выполнения
        данной роли.
