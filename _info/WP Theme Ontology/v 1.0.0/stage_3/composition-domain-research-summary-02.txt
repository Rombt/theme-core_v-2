COMPOSITION DOMAIN RESEARCH
SUMMARY
(Stage 2)

Status: Research

==================================================
1. PURPOSE OF THIS STAGE
==================================================

    Цель данного этапа исследования заключалась в определении
    минимального набора предметных знаний, которые должен
    предоставить автор темы для полного описания Composition.

    Исследование сознательно проводилось без рассмотрения
    реализации, формата хранения данных и программной модели.

    Единственным источником выводов являлся анализ предметной
    области на конкретных примерах.

==================================================
2. METHODOLOGY
==================================================

    Исследование выполнялось по следующему принципу:

        Предметная область
            ↓
        Конкретные примеры представлений
            ↓
        Выявление новой информации,
        необходимой для восстановления структуры
            ↓
        Формулирование предметных сущностей
        без преждевременного проектирования модели.

==================================================
3. IDENTIFIED INFORMATION
==================================================

    В результате исследования было установлено, что описание
    Composition содержит несколько различных видов информации.

    --------------------------------------------------
    3.1 Views
    --------------------------------------------------

        Composition должна содержать перечень представлений темы.

        Представление (View) является самостоятельным отображаемым
        состоянием темы, предназначенным для реализации конкретного
        пользовательского сценария.

        Примеры:

            Home

            Single Post

            Search

            Archive

            404

    --------------------------------------------------
    3.2 Composition Nodes
    --------------------------------------------------

        Каждое представление состоит из набора композиционных узлов.

        Композиционный узел представляет собой структурный элемент
        представления.

        На данном этапе исследования установлено, что Composition
        интересует сам факт существования узла, а не его визуальное
        представление или реализация.

    --------------------------------------------------
    3.3 Containment
    --------------------------------------------------

        Composition должна описывать отношения вложенности.

        Установлено существование отношения вида

            Parent contains Child

        которое определяет структуру дерева.

    --------------------------------------------------
    3.4 Root Node
    --------------------------------------------------

        Каждое представление должно иметь корневой узел,
        с которого начинается построение дерева Composition.

==================================================
4. DISCOVERED PROPERTIES OF COMPOSITION
==================================================

    В ходе дальнейшего исследования были выявлены свойства,
    которые невозможно выразить только существованием узлов.

    --------------------------------------------------
    4.1 Child Order
    --------------------------------------------------

        Порядок дочерних элементов является частью предметной области.

        Изменение порядка элементов изменяет Composition,
        даже если состав элементов остаётся неизменным.

        Следовательно, порядок является декларативным знанием
        о структуре.

    --------------------------------------------------
    4.2 Multiplicity
    --------------------------------------------------

        Было установлено различие между одиночными и повторяемыми
        дочерними элементами.

        Например,

            Header
                Logo
            и
            Posts
                Post

        имеют различную семантику.

        Во втором случае дочерний элемент представляет повторяемую
        структуру.

==================================================
5. IMPORTANT DISTINCTION
==================================================

    Исследование показало необходимость разделять две различные
    предметные области.

    --------------------------------------------------
    Composition Model
    --------------------------------------------------

        Описывает итоговую структуру представления.

    --------------------------------------------------
    Description Language
    --------------------------------------------------

        Предоставляет средства удобного описания этой структуры.

        Например, повторное использование общих фрагментов
        (Header, Footer и т.п.) не изменяет Composition,
        а лишь сокращает запись декларации.

        Следовательно, механизмы повторного использования не являются
        частью предметной модели Composition.

==================================================
6. INTERMEDIATE RESULT
==================================================

    Наиболее важным результатом данного этапа исследования стала
    следующая гипотеза:

        Большинство новых знаний, обнаруженных в процессе анализа,
        относятся не к самому композиционному узлу, а к способу его
        включения в структуру.

        К таким знаниям относятся:
            • положение среди соседних элементов;
            • кратность;
            • принадлежность конкретному родителю;
            • возможные будущие условия отображения;
            • возможные будущие правила замещения;
            • другие свойства включения элемента в Composition.

        из этого следует, что композиционный узел отвечает лишь на вопрос
            "Что представляет собой данный структурный элемент?"

        тогда как его включение в Composition отвечает на вопрос
            "Каким образом данный элемент участвует в структуре представления?"

    Данная гипотеза приводит к предположению, что центральной
        сущностью метамодели Composition может являться не сам композиционный узел, 
        а объект его вхождения (Composition Placement / Composition Inclusion).

    Именно объект вхождения потенциально объединяет в себе всю информацию:
        • какой узел используется;
        • в какого родителя он включён;
        • каким образом он включён;
        • какими свойствами обладает данное включение.

    При этом один и тот же Composition Node может иметь множество
        независимых вхождений в различных представлениях или
        в различных частях одного представления.

    Данная гипотеза требует дальнейшей проверки на более сложных
        сценариях построения Composition и является отправной точкой
        следующего этапа исследования.
