theme-core v-2
COMPOSITION DOMAIN
RESEARCH

Introduction
(v1.0.0)

Status: Research Foundation

==================================================
1. PURPOSE
==================================================

    Цель исследования — определить декларативный язык
    описания домена Composition.

    Исследование не направлено на проектирование PHP-классов,
    внутренних моделей или архитектуры реализации.

    Основная задача — выяснить, какую информацию должен
    предоставить автор темы, чтобы её было достаточно для
    построения готовой WordPress Theme.

==================================================
2. RESEARCH PRINCIPLE
==================================================

    Исследование ведётся от предметной области к реализации,
    а не наоборот.

    Последовательность работы:

        1. Определить информацию, которую должен описать
           автор темы.

        2. Сформировать декларативный язык предметной области.

        3. На основе полученной модели определить внутренние
           объекты приложения.

        4. Реализовать эти объекты в коде.

    Таким образом архитектура приложения становится
    следствием предметной области, а не её причиной.

==================================================
3. DOMAIN BOUNDARY
==================================================

    Исследование ограничено исключительно доменом
    Composition.

    Все выводы относятся только к описанию композиции темы.

    Другие домены (Design System, Templates, Assets,
    Rendering и т.д.) в рамках данного исследования
    не рассматриваются.

==================================================
4. RESEARCH METHOD
==================================================

    Исследование выполняется на конкретных примерах.

    Исходной точкой являются реальные элементы композиции, например:

        - site-title
        - navigation
        - post-loop
        - widgets
        - footer
        - header

    Для каждого элемента определяется информация,
    необходимая автору темы для его декларативного описания.

    Любые абстракции допускаются только после появления
    нескольких конкретных примеров, подтверждающих
    необходимость их существования.

==================================================
5. EXPECTED RESULT
==================================================

    В результате исследования должен быть сформирован
    декларативный язык описания Composition.

    Этот язык станет:

        - основой конфигурационного пакета;
        - источником для построения внутренней объектной модели;
        - эталонной методикой исследования остальных доменов
          theme-core v-2.
