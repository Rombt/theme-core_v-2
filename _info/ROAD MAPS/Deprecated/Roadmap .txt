Theme Core v-2
Roadmap разработки
Версия 0.1

Цель
Реализовать полный цикл компиляции WordPress Theme архитектуры
    Classic Theme + Elementor-first + Hybrid Features
    по одному конфигурационному пакету.

        ++ 1.1.1 Реализовать загрузку главной конфигурации
        ++ 1.1.2 Реализовать регистрацию доменов
        ++ 1.1.3 Реализовать сбор ThemeConfigurationPackage

    1.2 Реализация доменных конфигураций
        ++ 1.2.1 Assets

        1.2.3 Template Parts
        1.2.4 Layouts
        1.2.5 Menus
        1.2.6 Sidebars

        1.2.8 Image Sizes
        1.2.9 Widgets
        1.2.10 Integrations

    1.3 Валидация
        1.3.1 Проверка структуры пакета

        1.3.3 Проверка данных
        1.3.4 Проверка междоменных ссылок

        Компилятор способен полностью загрузить и валидировать `ThemeConfigurationPackage`.
