Classic Theme + Gutenberg-first + Design System–Driven Hybrid Architecture

    Тема реализована как классическая WordPress-тема,
        построенная вокруг дизайн-системы, определённой через theme.json, с
        Gutenberg как основным механизмом рендеринга и
        Elementor как вторичным, интегрированным инструментом.

    Ключевая архитектурная идея:
        Система строится не вокруг конкретного редактора,
        а вокруг единого слоя дизайн-системы:
            Design System (theme.json) → источник всех дизайн-токенов
            Gutenberg → нативная реализация дизайн-системы
            Elementor → внешний потребитель дизайн-токенов
        Инструменты не определяют архитектуру — они встраиваются в неё.



Classic Theme + Elementor-first + Hybrid Features

    Тема реализована как классическая WordPress-тема
        с PHP-шаблонами (header.php, footer.php, single.php и др.),
        где Elementor используется как основной инструмент построения интерфейсов страниц.

    Elementor-first подход означает:
        основные страницы (landing, home, marketing) создаются и редактируются в Elementor
        тема обеспечивает базовую разметку и минимальные стили, не конфликтующие с Elementor
        layout и компоненты на уровне страниц контролируются через Elementor, а не через шаблоны темы

    Hybrid features добавляют гибкость и покрывают edge-cases:
        поддержка Gutenberg (block editor) для контента (post/page)
        использование theme.json для глобальных настроек (цвета, типографика, spacing)
        наличие fallback-шаблонов для случаев, когда Elementor не используется
        частичное использование современных layout-техник (CSS Grid / Flexbox) внутри темы
        поддержка sidebar, widget areas и классических WordPress API


Classic Theme + Controlled Hybrid Architecture — тема с жёстким разделением зон ответственности:

    UI страниц → только Elementor
    Контент (post/page body) → только Gutenberg
    Тема → инфраструктура, ограничения, совместимость
    Никакой синхронизации дизайн-систем между системами

    Основной принцип: Изоляция вместо интеграции
