theme-core v-2
THEME IR NODES MODEL
(DRAFT v0.1.0)

Status: Discussion Draft

==================================================
1. PURPOSE
==================================================

    Данный документ фиксирует первоначальное понимание
    роли домена Nodes на стадии Theme IR.

    Документ не определяет окончательную реализацию.

    Его задача — сформировать целевую архитектурную модель,
    относительно которой в дальнейшем будет проектироваться
    реализация Theme IR.


==================================================
2. POSITION IN BUILD PIPELINE
==================================================

    Build Pipeline имеет следующий вид:

        Theme Configuration
                ↓
        Theme Components
                ↓
            Theme IR
                ↓
        Theme Artifacts
                ↓
        WordPress Theme

    Theme Components являются входной моделью
    стадии построения Theme IR.

    Theme IR является результатом
    детерминированного преобразования Theme Components.


==================================================
3. ROLE OF NODES
==================================================

    Nodes являются фундаментальными архитектурными единицами темы.

    Каждый Node описывает:

        архитектурную возможность;
        способ получения ресурса;
        тип поведения;
        поддерживаемые возможности.

    Composition определяет
    только структуру взаимодействия Node.

    Таким образом:

        Nodes отвечают
            ЧТО существует.

        Composition отвечает
            КАК это организовано.


==================================================
4. NODES IN THEME COMPONENTS
==================================================

    На стадии Theme Components Node остаётся
    декларативной моделью.

    Node содержит информацию,
    предоставленную конфигурацией.

    Theme Components не выполняют
    архитектурных преобразований.

    Они лишь представляют
    декларативное описание темы.


==================================================
5. NODES IN THEME IR
==================================================

    Theme IR не копирует Node
    из Theme Components.

    Theme IR строит
    собственную внутреннюю модель Node.

    Данная модель предназначена
    исключительно для работы компилятора.

    Theme IR не зависит
    от структуры конфигурационного пакета.

    Theme IR не обязан сохранять
    форму исходной конфигурации.


==================================================
6. TRANSFORMATION
==================================================

    Построение Theme IR выполняет
    детерминированное преобразование Node.

    Во время преобразования допускается:

        нормализация;
        объединение вычисленных данных;
        подготовка внутреннего состояния;
        построение связей;
        подготовка информации,
            необходимой следующим стадиям Pipeline.

    Преобразование не должно:

        изменять исходные Theme Components;
        обращаться к Theme Configuration;
        выполнять генерацию артефактов;
        выполнять материализацию.


==================================================
7. NODE IDENTITY
==================================================

    Каждый Node Theme IR
    сохраняет архитектурную идентичность
    соответствующего Node Theme Components.

    Один декларативный Node
    соответствует одному Node Theme IR.

    Theme IR не создаёт
    дополнительные Node,
    отсутствующие в Theme Components.


==================================================
8. COMPOSITION RELATIONSHIP
==================================================

    Composition в Theme IR
    продолжает ссылаться на Node.

    Однако ссылка должна указывать
    уже на Node Theme IR.

    Таким образом вся внутренняя модель
    Theme IR становится полностью независимой
    от Theme Components.


==================================================
9. RESOURCE STATE
==================================================

    Theme IR может содержать
    результаты подготовки ресурсов Node.

    Однако Theme IR
    не должен выполнять материализацию ресурсов.

    Theme IR хранит
    только архитектурное представление,
    необходимое последующим стадиям Pipeline.


==================================================
10. DESIGN PRINCIPLES
==================================================

    Модель Node Theme IR должна быть:

        независимой от конфигурации;

        независимой от файловой системы;

        детерминированной;

        неизменяемой после построения;

        пригодной
            для генерации Theme Artifacts;

        пригодной
            для дальнейшего развития Pipeline.


==================================================
11. NON-GOALS
==================================================

    Theme IR Node не отвечает за:

        генерацию файлов;

        выполнение рендеринга;

        выполнение WordPress Runtime;

        запись файлов;

        работу с конфигурацией.


==================================================
12. OPEN QUESTIONS
==================================================

    Требуют дальнейшего исследования:

        какие именно данные Node
        должны перейти в Theme IR;

        какие вычисленные данные
        должны появляться
        только в Theme IR;

        где проходит граница между
        Node IR
        и Render Model;

        каким образом Node IR
        будет использоваться
        генераторами артефактов.


==================================================
13. CURRENT CONCLUSION
==================================================

    На текущем этапе развития проекта
    принимается следующая архитектурная модель.

    Theme Components являются
    декларативной архитектурой темы.

    Theme IR является
    внутренней архитектурной моделью компилятора.

    Node существует
    на обеих стадиях Pipeline,
    однако представляет разные
    архитектурные модели.

    Theme Components описывают
    архитектуру пользователя.

    Theme IR описывает
    архитектуру компилятора.

    Переход между ними является
    детерминированным архитектурным преобразованием,
    выполняемым во время построения Theme IR.
