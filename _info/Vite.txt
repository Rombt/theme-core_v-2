Основные (Common Options)
    root: Путь до корневой директории проекта (где лежит index.html). По умолчанию — текущая папка.
    base: Базовый путь (Public Base Path). Важен при деплое в подпапку (например, /my-app/).
    plugins: Массив используемых плагинов (например, для поддержки Vue, React или PWA).
    publicDir: Директория со статичными ресурсами, которые копируются в корень сборки как есть.
    cacheDir: Папка для кэширования зависимостей (по умолчанию .vite).
    define: Глобальные константы, которые будут заменены в коде при компиляции.
    resolve: Настройки разрешения путей (алиасы типа @/, расширения файлов).
Сервер разработки (Server Options)
    server.host: IP-адрес, на котором будет слушать сервер (например, true, чтобы открыть доступ по локальной сети).
    server.port: Порт сервера (по умолчанию 5173).
    server.proxy: Настройки проксирования запросов к API, чтобы избежать проблем с CORS.
    server.open: Автоматическое открытие браузера при запуске.
    server.https: Настройка TLS/SSL для локальной разработки.
Сборка (Build Options)
    build.outDir: Имя папки для готовой сборки (по умолчанию dist).
    build.target: Целевая версия браузеров или окружения (например, esnext или es2015).
    build.sourcemap: Генерация карт исходного кода для отладки продакшн-кода.
    build.minify: Выбор минимизатора (esbuild — по умолчанию, или terser).
    build.rollupOptions: Прямой доступ к настройкам Rollup для сложной кастомизации сборки.
Оптимизация и CSS
    optimizeDeps: Тонкая настройка предварительной сборки зависимостей (пре-бандлинг).
    css: Настройки препроцессоров (Sass/Less), PostCSS и CSS-модулей.
Прочее
    envDir: Папка, где Vite ищет .env файлы.
    logLevel: Степень подробности логов в консоли (info, warn, error, silent).
    clearScreen: Очищать ли терминал перед выводом логов Vite.
